Справочник растений Tropic House — веб-приложение (PWA)

Что внутри: index.html (приложение и данные), img/ (фото), manifest.json и иконки (установка на экран «Домой»), sw.js (работа без интернета).

Как разместить бесплатно (один из вариантов):
1) Netlify: зайти на app.netlify.com/drop, перетащить ПАПКУ с этими файлами — сайт получит адрес вида xxx.netlify.app (нужно войти/зарегистрироваться, чтобы адрес не удалился).
2) GitHub Pages: создать репозиторий, загрузить файлы, Settings → Pages → Deploy from branch (main, / root).

Установка на iPhone: открыть адрес в Safari → «Поделиться» → «На экран Домой». После первого открытия работает без интернета.

Обновление: заменить файлы на хостинге новой версией — у пользователей обновится при следующем открытии с интернетом.
